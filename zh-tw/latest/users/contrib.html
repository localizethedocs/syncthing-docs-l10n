社群貢獻¶

本頁列出由社群建立的 Syncthing 整合、附加元件與封裝。與其他文件頁面相同，本頁可像 wiki 一樣編輯，歡迎直接修改並加入您的項目。

GUI 包裝程式¶

跨平台¶

  • Syncthing Tray

Android¶

  • Syncthing-Fork

    提供擴充功能的 Android 應用程式，搭配 Syncthing 執行檔使用。

Windows¶

  • `SyncTrayzor v2 <https://github.com/GermanCoding/SyncTrayzor>`_（GermanCoding 維護的 SyncTrayzor 分支，已更新支援 Syncthing v2）

macOS / iOS¶

  • syncthing-macos

    syncthing-macos 是原生 macOS 的 Syncthing 系統匣應用程式封裝。它可承載並包裝 Syncthing，使其更像原生 macOS 應用程式，而非需透過網頁瀏覽器操作的命令列工具。

  • Synctrain

    Synctrain 是一款開源的 iOS、iPadOS 與 macOS 原生應用程式，結合 Syncthing 與以檔案為中心的 UI，聚焦於選擇性與隨選同步。可從 App Store 安裝。

Linux¶

  • Syncthing Indicator

    GNOME Shell 擴充套件：提供 Syncthing 指示器，可透過 systemd 啟動、監控與控制 Syncthing 常駐程式。

  • Syncthing Toggle

    GNOME Shell 擴充套件：可快速開關 Syncthing systemd 服務並開啟 Web GUI。

  • SyncThingy

    以 C++ 撰寫的簡易系統匣指示器，面向 Flatpak 使用者。

  • syncthing-quick-status

    小型 bash 應用程式，依賴極少，以簡單彩色方式呈現目前狀態。

  • steamdeck-decky-syncthing

    可在 Steam Big Picture／Steam Deck UI 中控制 Syncthing 的 Steam Deck（Decky Loader）外掛。

命令列工具¶

  • STC

    Syncthing Cli：簡單的命令列工具，可在 shell／終端機中查詢狀態並執行基本操作，無需網頁瀏覽器。

  • syncthing-graph

    為 Syncthing config.xml 產生非常簡單圖表（dot 格式）的工具。

  • syncthing-map

    用於描繪 Syncthing 裝置與共享資料夾的跨平台工具。可產生多個裝置與其資料夾關係的視覺化圖示，包含特殊資料夾類型（僅傳送、僅接收）。需以各裝置的 XML 設定檔作為輸入。

套件與封裝¶

跨平台¶

  • Webi：syncthing

    Mac、Linux：:

    $ curl -sS https://webinstall.dev/syncthing | bash

    Windows 10（build 1803）或更新版本:

    > curl.exe -A MS https://webinstall.dev/syncthing | powershell

Windows¶

  • Syncthing Windows Setup

    使用 Inno Setup 建立的輕量但功能完整的 Windows 安裝程式。支援管理員與一般使用者安裝、自動啟動、防火牆整合與靜默安裝。

Debian / Ubuntu¶

  • 官方套件：https://apt.syncthing.net/

  • Debian 套件：syncthing、syncthing-discosrv 與 syncthing-relaysrv

Fedora / CentOS¶

對於 Fedora，Syncthing 現已在官方套件庫：https://src.fedoraproject.org/rpms/syncthing

非官方 Syncthing RPM 套件庫 <https://copr.fedorainfracloud.org/coprs/daftaupe/syncthing/>`_（`原始碼）

Arch Linux¶

  • 官方 Extra 套件庫：syncthing

  • Arch User Repository：syncthingtray-qt6

Docker¶

  • docker-syncthing <https://docs.linuxserver.io/images/docker-syncthing>`_（由 `LinuxServer 提供）

  • Syncthing 與 Syncthing Discovery Server 的 Dockerfile。兩者皆使用最新二進位發行版。

  • docker-syncthing：完整可用的 Docker 容器，支援自訂設定，且在 Docker 映像重啟後仍保留設定與資料。

  • syncthing-docker-scratch：從 scratch 基底建置 Docker 容器，並可在 docker 或 rkt 中執行。

  • rpi-syncthing：可設定的 Raspberry Pi 映像。

  • Syncthing for Home Assistant OS：Home Assistant Operating System 的 Docker 型附加元件

Gentoo¶

官方 net-p2p 套件：syncthing

FreeBSD¶

FreshPorts：syncthing

macOS¶

MacPorts：syncthing

$ sudo port install syncthing

OpenBSD¶

官方 ports：syncthing 與 QSyncthingTray

OpenSUSE¶

官方套件：syncthing 與 qsyncthingtray

Synology NAS（DSM）¶

  • Synocommunity：在 DSM 的套件中心加入 http://packages.synocommunity.com/，或查看 可瀏覽的套件庫。支援多種 CPU 架構。SPK 版本可能較舊，但安裝後可透過 Web GUI 進行 Syncthing 升級。

QNAP NAS（QTS）¶

`Syncthing QPKG <https://www.myqnap.org/product/syncthing/>`__（Qnap Package）可用於所有 x86、x86_64、Arm 機型（含新機型）。另見以 root 執行 Syncthing：<https://www.myqnap.org/product/syncthing-run-as-root/>

RockStor¶

Docker 容器 與 registry 條目

Cloudron¶

Syncthing 可在 Cloudron 以一鍵安裝。若您不熟悉，Cloudron 可讓您更容易在伺服器上執行應用程式，並保持更新與安全。

提供 `示範站點 <https://my.demo.cloudron.io>`_（username: cloudron password: cloudron）

Cloudron 套件開發位置在 這裡。

WD My Cloud NAS¶

可在 WDCommunity 取得 OS3 套件。

整合¶

REST API 繫結¶

  • Python：https://github.com/blakev/python-syncthing（https://pypi.org/project/syncthing/）

  • PHP：https://github.com/terzinnorbert/syncthing-rest

組態管理¶

  • puppet-syncthing

  • ansible-syncthing

  • 命令列介面：syncthingmanager

  • syncthing-configd

    可自動管理 Syncthing 組態部分項目的常駐程式，例如依規則自動接受或移除裝置／資料夾。

監控¶

  • `sm²（Syncthing Multi Server Monitor）<https://github.com/nware-lab/sm2>`_

    一個用於「以盡可能少的磁碟空間與記憶體監控多個 Syncthing instance」的 Docker 容器。

解決衝突¶

  • syncthing-resolve-conflicts

    用來處理使用 Syncthing 時可能出現之文字檔同步衝突的小型 bash 腳本。靈感來自 Arch Linux 的 pacdiff 工具。可搭配 diff 工具合併檔案並保持最新。

  • syncthing_merge_babashka

    使用 Clojure 與 Babashka 撰寫的小型腳本（因此需要 Babashka 依賴），可協助透過 emacsclient、vimdiff 或其他工具解決衝突。它會接收一個目錄，找出每個衝突，並讓使用者決定要開啟合併程式或略過該檔案。
